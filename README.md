# Stouls Studio site

English showcase site for Stouls Studio (Margaux Stouls, interior architect, Paris), aimed at US and Canadian buyers.

- Edit copy in `src/pages-core.mjs` and `src/pages-guide.mjs`, styles in `src/styles.css`.
- Contact details, site URL and the indexing switch are in `site.config.json`.
- Build: `node build.mjs` (no dependencies). Output goes to `docs/`, which GitHub Pages serves.
- Photos: see `photos/README.md`.

Before going live on the final domain: set `siteUrl`, `whatsapp`, `email`, set `indexable` to `true`, add the domain in the repo's Pages settings, rebuild.

Legal figures in the guide were checked on 11 November 2026 against the sources linked on the page. Re-check before editing them.
