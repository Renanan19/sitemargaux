# Photos

Drop files here, then run `node build.mjs`. The file name decides where each one goes (jpg, webp, png or avif):

- `hero` : tall portrait shot, shown in the arch on the home page (replaces the drawn plan)
- `project-1` to `project-6` : home page gallery, portrait 4:5 works best
- `margaux` : portrait on the About page

Keep each file under about 400 KB (2000 px on the long side is plenty).
